# Zona Cero Mobile App

Expo + React Native boilerplate for Zona Cero.

## Stack

- Expo SDK 56
- React Native 0.85
- TypeScript
- Expo Router
- pnpm

## Commands

```bash
pnpm install
pnpm start
pnpm ios
pnpm android
pnpm web
pnpm typecheck
```

## Scope

This is only the app boilerplate. It intentionally does not implement the first technical spike: no RxDB, SQLite persistence, signed outbox, sync, MapLibre, or Meshtastic gateway logic yet.
