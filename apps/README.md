# Apps

Application workspaces for Zona Cero.

## Naming

- `apps/mobile`: current Expo React Native app. The code still lives at the repo root until migration phase 1.
- `apps/web-ui`: secure web links and lightweight operational panels.
- `apps/telegram-channel`: Telegram conversation flows and channel adapters.

## Ownership

- Equipo A owns `apps/web-ui` and `apps/telegram-channel`.
- Equipo C owns `apps/mobile`.
- Equipo B reviews integration points that cross API, contracts, auth, and webhooks.
